☁️ Nhập/Xuất Excel · Sao lưu · Đồng bộ Nhiều Máy
1. Nhập / Xuất File Excel (.xlsx) từ Google Sheets
Tải file Google Sheets hiện tại về máy dạng Microsoft Excel (.xlsx) rồi chọn file tại đây. Hệ thống tự nhận diện đầy đủ các sheet DanhSachTinBao*, ChiTieu*, KienNghi*, TamDinhChi.
Xuất toàn bộ các sheet ra file .xlsx được tô màu nền theo tháng, màu chữ theo trạng thái (xanh lá = đã GQ, tím = TĐC, đỏ đậm = quá hạn...) giống hệt hàm formatSheetTinBao.

3. Đồng bộ Cloud (Supabase) giữa nhiều máy tính
💡 Cách đồng bộ nhiều máy:
• Cách A (Triển khai lên Render / Railway / VPS hoặc Mạng LAN): Mở đường link web của máy chủ trên bất kỳ máy nào là tất cả đều dùng chung 1 cơ sở dữ liệu trực tiếp, không cần cấu hình thêm.
• Cách B (Kết nối Supabase Cloud miễn phí): Nếu bạn chạy phần mềm độc lập ở nhiều máy khác nhau, điền Project URL và Anon/Service Key của Supabase (tạo bảng vks_app_state (id text primary key, data jsonb, updated_at timestamptz)) để các máy tự động đồng bộ.
